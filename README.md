# graduation-project
WI-FI Controlled drone 
Project Overview
In our graduation project, we successfully designed a Wi-Fi Controlled Drone. 
The primary goal of this project was to create a drone that could be operated wirelessly through a Wi-Fi connection,
enabling both remote control and monitoring. Despite facing multiple challenges during the development process,
we successfully achieved our objectives and delivered a fully functional system.
Attached Files
WIFI_DRONE_GH:
This file contains all the research, documentation, and work that went into designing the drone.
codeWIFIDRONE:
This file includes the C code used to program the drone and manage its functionality.
QuadCopterParts:
This file contains all the parts and the software used in this project
